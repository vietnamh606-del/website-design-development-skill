# Example Requests

Use these as prompts after the skill is available in VS Code Copilot Chat.

## Create a new static website
"Create a polished responsive website about [topic] using HTML, CSS, and vanilla JavaScript. First inspect the workspace. Use existing assets, implement working navigation and interactions, and tell me how to run it."

## Improve an existing website
"Review the current website and improve its visual quality to a professional standard. Preserve existing content and working behavior. Inspect before editing, make focused changes, and run available checks."

## Cinematic biography website
"Create a cinematic biography website about [subject] with a dark visual system, hero section, biography timeline, image gallery, interactive details, scroll animations, and responsive mobile layout. Use the project's existing stack and assets. Avoid fake buttons and verify all asset paths."

## Convert screenshot into a layout
"Analyze the supplied screenshot and implement a close responsive recreation. Match layout, hierarchy, colors, typography, spacing, and image crops as closely as practical. Do not claim pixel-perfect accuracy without checking it in a browser."

## Debug a frontend issue
"Reproduce and diagnose the reported issue before changing code. Inspect relevant files and console/terminal output if available. Fix the root cause with the smallest safe change, then rerun relevant checks and report what passed."

## Add a React component
"Inspect the existing React architecture and styling system. Implement [component/feature] using existing conventions, responsive behavior, accessible interactions, and the current test/build scripts. Do not add dependencies unless necessary."
