# Design Checklist

Use this checklist to create a coherent design. Adapt it to the project's purpose; do not force every visual effect into every website.

## Before coding
- [ ] Identify audience, purpose, and primary action.
- [ ] Review screenshots, brand assets, copy, and existing design conventions.
- [ ] Choose one clear visual direction.
- [ ] Decide page sections and their order.
- [ ] Select a small palette with semantic roles: background, surface, text, muted text, accent, border, and status colors.
- [ ] Select a readable type scale and consistent spacing rhythm.

## Layout
- [ ] Create a clear first viewport with a useful headline and primary action where relevant.
- [ ] Use consistent max-widths and alignment.
- [ ] Group related content and leave intentional whitespace.
- [ ] Use a responsive grid/flex layout rather than fixed desktop-only dimensions.
- [ ] Keep navigation and page hierarchy predictable.
- [ ] Make long pages easy to scan with sections and meaningful headings.

## Visual details
- [ ] Use consistent button, card, input, and link styles.
- [ ] Use a restrained set of shadows, borders, radii, and effects.
- [ ] Keep image aspect ratios and focal points intentional.
- [ ] Ensure text over images has sufficient contrast.
- [ ] Avoid emoji as a replacement for a coherent icon system unless appropriate to the design.
- [ ] Avoid gratuitous gradients, glows, glass effects, and animation.

## Interaction
- [ ] Define hover, focus, active, disabled, and error states as applicable.
- [ ] Make all controls keyboard-operable.
- [ ] Keep motion brief and meaningful.
- [ ] Respect reduced-motion preferences.
- [ ] Ensure touch users can access the same essential functionality as mouse users.

## Responsive checks
- [ ] Small mobile (~320–390 CSS px).
- [ ] Large mobile / small tablet (~600–768 CSS px).
- [ ] Laptop (~1024–1366 CSS px).
- [ ] Wide desktop (~1440 CSS px and above).
- [ ] No accidental horizontal scrolling.
- [ ] Images, headings, navigation, cards, and buttons adapt gracefully.

## Final polish
- [ ] No placeholder copy unless intentionally requested.
- [ ] No broken links or missing assets.
- [ ] Consistent spacing and typography.
- [ ] Clear focus indicators and adequate contrast.
- [ ] Empty/error/loading states exist where needed.
- [ ] Page still makes sense if animations are disabled.
